# РПК «Алфавит» — сайт v1

Первая полноценная версия сайта для публикации через GitHub → Cloudflare.

## Файлы
- `index.html` — структура сайта
- `style.css` — дизайн и адаптив
- `main.js` — мобильное меню, анимации и демонстрационный калькулятор

## Что нужно заменить перед финальной публикацией
1. Телефон и email в футере.
2. Реальные фотографии работ в портфолио.
3. Реальные сведения о производстве и оборудовании.
4. Формулу калькулятора на утверждённые цены.
5. Подключить рабочую форму отправки заявки.
6. Подключить основной домен.

## Публикация
Загрузите эти три файла в корень репозитория `alfavit` на GitHub. Cloudflare должен автоматически запустить новое развёртывание.
