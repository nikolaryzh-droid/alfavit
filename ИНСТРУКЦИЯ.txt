Как обновить GitHub:
1. Распакуйте ZIP.
2. Откройте репозиторий alfavit.
3. Add file → Upload files.
4. Выберите ВСЕ файлы из этой папки.
5. Commit changes.
6. Старые hero-concept.svg и service-*.svg можно не удалять сразу: новый index.html их больше не использует.
7. После успешной проверки сайта старые SVG можно удалить позже.
