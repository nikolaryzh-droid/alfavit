РПК «Алфавит» — версия для загрузки с iPad

В этой папке НЕТ вложенных папок.
Все файлы должны находиться в корне GitHub-репозитория alfavit.

КАК ЗАГРУЗИТЬ:
1. Распакуйте ZIP в приложении «Файлы» на iPad.
2. Откройте папку alfavit-ipad-upload.
3. В GitHub откройте репозиторий alfavit.
4. Выберите Add file → Upload files.
5. В окне выбора файлов нажмите «Выбрать» и выделите ВСЕ файлы из папки.
6. Загрузите их.
7. Нажмите Commit changes.
8. Старые index.html, style.css и main.js должны быть заменены.
9. Cloudflare автоматически запустит новое развёртывание.

ВАЖНО:
Папка assets от предыдущей попытки больше не нужна для этой версии.
