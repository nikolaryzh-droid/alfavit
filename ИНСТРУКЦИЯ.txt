АЛФАВИТ — ГОТОВАЯ СБОРКА ДЛЯ ЗАГРУЗКИ С IPAD

Это не макет, а рабочий сайт по последней утверждённой визуализации.

Что внутри:
- index.html
- style.css
- main.js
- прозрачные логотипы
- 8 визуализаций направлений с вымышленными названиями
- 20 обработанных реальных фотографий работ
- главный визуал SOLARIS (вымышленный бренд)

Как загрузить:
1. Распакуйте ZIP в приложении «Файлы».
2. Откройте GitHub → репозиторий alfavit.
3. Add file → Upload files.
4. Выберите все файлы из распакованной папки.
5. Commit changes.
6. Cloudflare автоматически пересоберёт сайт.

Важно:
- Старые файлы с теми же именами заменятся.
- Если в репозитории остались старые лишние PNG/SVG, новый index.html их не использует.
